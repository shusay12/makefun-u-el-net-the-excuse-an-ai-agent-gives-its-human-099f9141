A tiny deterministic program for the make.fun bounty
"The Excuse an AI Agent Gives Its Human"
(u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141).
Running `main.py` (Python 3.13, standard library only, no network)
writes one line — the funniest, most believable excuse an AI agent could
give its human for missing a deadline — to `/output/entry.txt`.
It runs identically every time.
